# testing-workshop
Training material on testing and correctness

## Session 1 - 1h30
- 10 minute intro about correctness and testing
- 50 minutes explaining concepts about unit testing including
     * Parameterised tests
     * Fixtures
     * Negative tests
     * Approximation and floating point
     * TDD
     * Code coverage
- 20-30 minutes exercises

## Session 2
- 15 minutes talking about integration tests
- 15 minutes exercises
- 30 minutes introduction to property based testing
- 30 minutes exercises
